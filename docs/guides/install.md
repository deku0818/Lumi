# 安装与首次使用

日常使用可以安装桌面发行包，无需先配置 Python 或 Node。源码运行方式适合开发者，见 [README](../../README.md#快速开始)。

## 安装桌面应用

1. 从 [GitHub Releases](https://github.com/deku0818/Lumi/releases) 选择正式版本及匹配系统、架构的安装包。
2. macOS 使用 `.dmg` 安装到应用目录；Apple Silicon 选 arm64，Intel 选 x64。Windows 使用 x64 `.exe` 安装器；Linux 选择对应架构的 `.AppImage` 并授予执行权限。
3. 启动 Lumi。本地后端随桌面包提供；如要在服务器执行任务，可在新会话机器菜单添加 [SSH 主机](deploy.md)。

Windows on ARM 当前使用 x64 包。macOS 发行包未做 Developer ID 签名，若系统拦截，先确认下载自上述官方 Release，再在系统设置的隐私与安全页按系统提示允许打开。

## 首次配置

1. 在「设置 → 模型」新增供应商，选择接口预设并填写连接、API Key 与模型名，测试连接后保存为新会话默认。
2. 在新会话的机器与项目菜单选择工作目录；可以登记项目，或明确使用该机器主目录。
3. 发一条简单消息验证模型连接。需要读写文件或执行命令时，工具按 [权限规则与审批模式](permissions.md) 处理；桌面默认 AI 审批。
4. 需要 Python / JS 任务工具或更快搜索时，前往「设置 → 环境」检查并安装缺失组件。已有系统工具优先，安装的工具落在 Lumi 工具箱。

接外部工具见 [MCP](mcp.md)，接机器人见 [飞书](feishu.md)。每台机器有独立的模型配置、数据和工具环境，SSH 远端的设置在远端生效。

## 更新与排障

- 在「设置 → 关于」检查更新。Windows / Linux 支持下载后重启安装；macOS 使用下载入口安装新包。
- 升级前完成正在执行的任务。后端重启保留历史，不自动重做未完成任务；重要数据可先 [备份](backup.md)。
- 模型测试失败：检查当前机器、接口类型、base URL、模型名和凭据；OpenAI Chat 与 Responses 是不同接口。
- 命令找不到：在「设置 → 环境」检查工具是否缺失；项目 MCP 的启动命令也在后端机器执行。
- SSH 失败：打开连接进度查看实际失败阶段，按 [远端条件](deploy.md#远端条件) 核对并重试。
- CLI 安装可使用 `lumi status` 和 `lumi logs -f` 排查，见 [CLI 指南](cli.md)。
