# 记忆与项目说明使用指南

Lumi 会跨会话记住关于你和项目的关键信息，并会在处理项目任务时按需读取 `AGENTS.md` 中的项目约定。
你基本不用管它——对话里告诉它该记的，它自己存；下次对话自动带上。

---

## 持久记忆：让 Lumi 记住

直接在对话里说，它就会存下来：

```
你：以后回复简短点，别在结尾总结
Lumi：好的（存为 feedback 记忆）

你：我主要写后端，React 是新手
Lumi：明白（存为 user 记忆，以后前端的解释会给你多铺垫）
```

也可以显式要求：「记住……」「忘掉关于……的记忆」。

**它会记什么**（四类）：
- **你是谁**（角色、专长、偏好）
- **怎么协作**（你纠正过 / 确认过的工作方式）
- **项目背景**（进行中的事、事故、决策等代码里看不出的上下文）
- **外部指针**（bug 在哪个看板、文档在哪）

**它不会记什么**：代码结构 / git 历史 / 调试修复配方 / 临时状态——这些读代码或 `git log` 即可得知。
即便你让它存这类，它会反问「哪里是不显然的」，只留那部分。

### 存在哪

`~/.lumi/memory/projects/<你的项目路径>/`，按项目隔离、跨会话保留。里面：
- `MEMORY.md` —— 索引（每行一条，开会话时整体进上下文）
- 各 `*.md` —— 单条记忆正文（需要时 Lumi 自己通过 bash 搜索或 read 读取）

> 记忆可能过时。Lumi 在据某条记忆推荐前会先验证（提到的文件/函数是否还在），与现状冲突时以现状为准并更新记忆。

### 关于审批

写记忆文件**不会弹审批**（记忆的价值就是不打断对话）。但你配置的 DENY 规则仍然
拦得住它——免审批只免掉「本该问你一下」那一步。

## `AGENTS.md`：项目说明

在项目根放一个 `AGENTS.md`，写这个项目的约定、对 Lumi 的指示，处理相关任务时 Lumi 会通过工具读取，正文不会在会话开头自动加载：

```markdown
# 本项目约定
- 依赖用 uv 管理，别直接改 pyproject
- 测试命令：uv run pytest
- 提交信息用中文
```

- 主 agent 和子 agent 都带有按需读取规则：先检查项目根，进入子目录工作前检查沿途的同名文件；更深层的约定在对应目录内优先。
- 已读取的说明可在当前任务中复用；得知文件更新后重新读取。
- 原来的 `LUMI.md` 请重命名为 `AGENTS.md`，旧文件名不再使用。
- `.lumi/prompts/AGENTS.md` 是独立的 style 系统提示词配置，仍按原有配置规则加载。
- 它和「持久记忆」是两回事：`AGENTS.md` 是你手写的项目规矩，记忆是 Lumi 自己积累的。
- `AGENTS.md` 是否进 git 由你决定：不想提交就自行加入 `.gitignore`。

---

## 关掉记忆

记忆默认只对**面向用户的桌面/对话会话**开启；子 agent、workflow 不带记忆。定时任务（cron）的每次执行也是一个普通会话，同样带记忆（会读取、也能写入），但不会自动触发整理（autoDream）。
目前没有关闭记忆的开关：清空 `~/.lumi/memory/projects/<项目>/` 只是清除已有记忆，之后仍会继续记（`AGENTS.md` 的按需读取规则不受影响）。
