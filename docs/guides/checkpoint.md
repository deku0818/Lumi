# 聊天历史与重新生成

桌面端先显示最近 50 个聊天条目，向上滚动时继续加载更早的记录，包括压缩前的完整原文与工具结果。加载较早记录不会扩大模型当前使用的上下文；加载失败可重试，旧 checkpoint 已被清理时会提示较早记录不可用。

仍在当前模型上下文中的用户消息可「重新生成」或「编辑后重发」：该消息之后的当前对话被截断后重走一轮。仅存在压缩前记录中的用户消息只支持查看和复制。

如果目标消息曾在压缩中保留，重答前会恢复其压缩前的上下文，再截断目标及之后的内容，避免旧回答或工具结果影响重答。必需记录已不可用时会拒绝回退，保留当前对话。

**只回退对话，不回退文件**——Agent 已改动的文件原样保留。Lumi 没有沙箱，重要改动请用 git 管理，需要时自行 `git restore`。
